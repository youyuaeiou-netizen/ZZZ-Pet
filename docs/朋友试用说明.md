# DesktopPet 0.3.1-beta.3 试用说明

本版本只包含用户选定的二维 Q 宠和 11 组动作。请从 GitHub Release 下载 beta3 ZIP，退出正在运行的桌宠，完整解压到一个新文件夹后运行 `DesktopPet.exe` 或 `Start-2D-Pet.cmd`。ZIP 为 Windows x64 自包含包；不需要单独安装 .NET。

默认使用 `ellen-flat2d`，包含 540 帧透明动画。不删除用户数据。

右键角色或托盘图标可打开功能菜单。可在角色菜单切换动画、调整大小与位置、隐藏或显示角色。要退出程序，请从托盘菜单选择退出。

## 动作

待机、挥手、入睡、坐睡、醒来、开心、被抚摸、喂食、伸懒腰、拖起悬空和放下。拖动角色可触发悬空动作，松开后播放放下动作。

## 文件搜索

“文件范围”选择某个磁盘时，检索该磁盘上的文件和文件夹；“全部电脑”覆盖本机所有固定磁盘、已连接的移动磁盘、映射网络磁盘和光盘。无需先手动添加目录，也不要求文件已被 Windows 索引。

搜索按名称和路径匹配，支持中英词库与自定义别名。Everything 或 Windows 索引提供快速候选，程序同时直接遍历磁盘并逐步显示结果；首次或大磁盘搜索可能耗时较长，可随时换关键词或关闭搜索窗口取消。列表显示排名最高的前 80 项，但继续扫描整个范围，不以结果数量停止扫描。

已有结果可立即打开；“已找到结果，正在补全”表示仍在检查剩余磁盘内容，结束后显示“检索完成”。补全过程保留已有结果行的位置和选中项，后台目录变化不会反复清空或重启当前搜索；需要重查时点击“刷新”。详细扫描信息可悬停查看底部状态。

受权限限制、断开的磁盘或无法读取的位置会明确提示结果不完整。链接目录本身可以找到；不重复展开其目标，以避免越出选定磁盘或循环遍历。新建文件在下次搜索时直接检索。

## 帧率显示

启用 FPS 后，优先显示当前应用及其渲染进程的呈现帧率；桌面或当前应用无有效帧数据时，使用 PresentMon 采集的 Windows 桌面合成帧率，明确标为“桌面 FPS”。观看视频时也可使用这个回退，但桌面合成帧率不等于视频源的帧率。切回桌面会清除之前应用的目标；打开宠物设置仍保留正在查看的应用目标。

FPS 采集沿用管理员授权，不安装驱动、不修改权限。采集未启动、权限不足或超过三秒没有有效帧数据时保留明确状态，不伪造数值。连续十秒没有有效帧时显示“FPS 采集无数据”；连续二十秒无帧时自动重建一次采集会话，收到帧后恢复数值。若重建后仍无帧则保持无数据，不循环重启。关闭与 FPS 无关的 GPU 耗时和输入延迟跟踪，仍保留桌面呈现跟踪。

## 重新生成动画

本仓库保留逐动作提示词、源视频、角色参考图和帧处理程序。制作步骤及许可边界见 [`workflow/制作工作流.md`](../workflow/制作工作流.md) 和 [`workflow/LICENSE-ASSETS.md`](../workflow/LICENSE-ASSETS.md)。

解压使用前可用发布页提供的 `.sha256` 文件核对 ZIP 完整性。首次运行建议检查当前 Windows 缩放比例下的角色清晰度与位置。
